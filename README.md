# Web-Scrapping-Project
# Flipkart Web Scraping and Product Analysis

## Project Overview
This project focuses on collecting, cleaning, and analyzing Flipkart product data using Python.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `notebooks/` – Python analysis notebook
- `dataset/` – Project datasets
- `Reports/` – Analysis report
- `visualizations/` – Generated charts and graphs

## Key Analysis
- Product price distribution
- Discount percentage analysis
- Top 10 brands
- Top product categories
- Price correlation analysis

## Objective
To analyze e-commerce product data and generate meaningful insights through Python data analysis and visualization.
